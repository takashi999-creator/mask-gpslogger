# MASK.GPSLOGGER

決めた条件で地点を記録し、標高・天気・風・写真・その場の音を一緒に残すGPSロガーです。

## できること

- 時間の間隔と移動距離で自動記録（「どちらか」「両方」「時間だけ」「距離だけ」）
- 「今ここを記録」でカメラを開き、撮った写真に日時・緯度経度・標高・天気・気温・湿度・風を書き込む
- 自動記録のたびに周囲の音を数秒録る（設定でオン）、音声メモ（最大60秒）
- 標高は国土地理院、天気は Open-Meteo、場所の名前は OpenStreetMap、野鳥は iNaturalist、名所は Wikipedia から取得
- 圏外で記録した地点は、電波が戻った時にその時刻の天気を補う
- 地理院地図・航空写真・OpenStreetMap、標高グラフ、GPX／CSV書き出し
- アプリ版は画面を消しても記録が続く（通知が表示されます）
- 日付別・場所別・「写真や音声あり」での絞り込み、写真と音声の一覧
- 記録・写真・音声を1つのzipにまとめるバックアップと、その読み込み

## PCで見る

1. スマホで「記録の条件と設定」→「バックアップ（写真・音声つき）」を押し、できたzipをPCへ送る（Googleドライブ、メール、USBなど）
2. PCのブラウザでウェブ版（`https://ユーザー名.github.io/リポジトリ名/`）を開く
3. 「記録の条件と設定」→「バックアップを読み込む」でzipを選ぶ

PCでは左に地図、右に記録が並びます。同じzipを何度読み込んでも重複しません。
zipの中の `photos` と `audio` は、そのまま写真・音声ファイルとして開けます。

## フォルダ

| 場所 | 中身 |
|---|---|
| `www/` | アプリの画面すべて（`index.html` が本体） |
| `android/` | Androidアプリのプロジェクト（Capacitor 7） |
| `.github/workflows/android.yml` | GitHub上でAPKを作る手順 |
| `.github/workflows/pages.yml` | ウェブ版を https で公開する手順 |

## 使い始める手順

1. GitHubで新しいリポジトリを作り、このフォルダの中身を `main` ブランチに入れる
2. 自動で2つの作業が走る（リポジトリの「Actions」タブで進み具合が見える）
   - **ウェブ版を公開する**：`https://ユーザー名.github.io/リポジトリ名/` で開けるようになる
   - **Androidアプリを作る**：5〜10分ほどでAPKができる
3. スマホで `https://github.com/ユーザー名/リポジトリ名/releases/latest` を開き、`MASK-GPSLOGGER.apk` をタップ
4. 「提供元不明のアプリ」の許可を求められたら許可してインストール
5. 初回に位置情報・通知・カメラ・マイクの許可を求められるので許可する

公開リポジトリなら無料で使えます。非公開リポジトリでは、ウェブ版の公開（GitHub Pages）に有料プランが必要です。

## 画面を消しても記録を続けるために

Androidの省電力機能がアプリを止めることがあります。記録が途切れる時は、スマホの
「設定 → アプリ → MASK.GPSLOGGER → バッテリー」を「制限なし」にしてください。

## 知っておくこと

- 記録・写真・音声はスマホの中だけに保存されます。アプリを消すと一緒に消えるので、残したいものは書き出してください
- 画面を消している間は、音の自動録音は行いません（Androidの制限）
- 写真の自動撮影はできません（シャッターは自分で押します）
- 野鳥の一覧は観察記録で、その瞬間にいる鳥ではありません
- APKは開発用の鍵（`android/app/debug.keystore`）で署名しています。自分用として使う前提です

## 画面を直した時

`www/index.html` を直して `main` に入れると、ウェブ版とAPKの両方が作り直されます。
新しいAPKは上書きインストールでき、記録は残ります。
